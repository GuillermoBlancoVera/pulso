# PULSO · Business plan interactivo

Plan de negocio de PULSO: producción técnica y musical para bodas y eventos (ceremonias, DJ y banda en directo).

- **Web publicada:** https://guillermoblancovera.github.io/pulso/
- **En local:** descarga el repositorio y abre `index.html` en el navegador. La carpeta `img/` tiene que estar junto al HTML.

La página incluye el inventario de equipamiento con decisiones de compra o alquiler, el simulador financiero y la hoja de ruta. Los cambios se guardan en el navegador de cada persona.
